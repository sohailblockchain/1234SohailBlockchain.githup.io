# Lab Supervisor Portfolio — Sohail Ahmed

A focused collection of five practical lab-management projects created for demonstrating skills relevant to a university Computer Science Lab Supervisor role.

## Projects

1. **Lab Asset & Inventory Manager** — track computers, devices, condition, allocation, warranty and maintenance.
2. **Network Health Monitor** — simulate device uptime, latency, IP status, alerts and basic diagnostics.
3. **Student Attendance & Lab Booking System** — manage lab sessions, attendance, bookings and utilization.
4. **IT Helpdesk & Software Deployment Dashboard** — manage tickets, software requests, priorities and deployment status.
5. **Lab Incident & Preventive Maintenance System** — log incidents, schedule maintenance, track resolution and compliance.

## Skills Demonstrated

- Computer lab operations
- Hardware/software troubleshooting
- Networking fundamentals
- Asset and inventory management
- Student/faculty support workflows
- Documentation and reporting
- Dashboard UI development
- JavaScript state management
- Practical problem solving

Each project is a standalone HTML/CSS/JavaScript demo and can run directly in a browser without installing dependencies.

## Interview Demo Flow

Open each project and explain:
**Problem → Lab workflow → Technical solution → Key features → How it improves reliability and student support.**
